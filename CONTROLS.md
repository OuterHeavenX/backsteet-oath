# Controls

All bindings can be changed in **Controls** (title screen or pause menu), with **Reset to defaults**.
Prompts in the game follow the device you used last (keyboard, controller or touch).

| Action | Keyboard (primary / alternate) | Controller (Steam Deck / Xbox layout) | Touch |
|---|---|---|---|
| Move (street depth too) | W A S D / Arrow keys | Left stick / D-pad | Left pad |
| Punch / confirm | J / Z | X (left face button) | PUNCH |
| Kick | K / X | Y (top face button) | KICK |
| Jump | Space / C | A (bottom face button) | JUMP |
| Guard | L / V | LB or LT | GUARD |
| Grab / Talk / Throw / Enter | E / F | B (right face button) | ACTION (label changes: TALK, ENTER, PICK UP, LIFT, GRAB, THROW, BUS) |
| Run (hold) | Shift / B — or double-tap left/right | RB or RT — or double-tap | RUN |
| Status & bag | Tab / I | View | BAG |
| Pause | Esc / P | Menu | PAUSE |

**Touch:** phones and tablets start in touch mode automatically. Controls appear only while you're using touch,
so pressing a key or a controller button hides them again; Settings → Touch controls can force On or Off.
Tablets and other taller screens get a dedicated control deck under the street. Phones show the controls
over the street's lower corners, and they disappear during conversations. Tap the street or the text box to
continue dialogue, or use **SKIP**. Every menu has a **< Back** button.

Menus: arrows/WASD or D-pad/stick to move, **Enter/Space/J/E** or **A** to confirm, **Esc/Backspace/K** or **B** to go back.
**Q / R** or **LB / RB** switch tabs in the Status screen. Dialogue: **Punch/Confirm** advances, **Back** skips the scene.

## Moves
| Move | Input |
|---|---|
| Punch combo | Punch, Punch, Punch (third hit is a knockdown hook) |
| Kick finisher | Punch, Punch, Kick (roundhouse, hits a crowd) |
| Jump kick / jump punch | Jump, then Kick / Punch |
| Running punch / dropkick | While running: Punch / Kick |
| Guard / Perfect guard | Hold Guard. Pressing it just before a hit staggers the attacker |
| Grab | Grab near a dizzy (stars) or knocked-down enemy, then Punch/Kick/Grab to throw |
| Pick up / lift | Grab near a weapon, crate or trash can. Punch swings; Grab throws |
| Drop item | Hold Guard + Grab |
| Enter a door | Walk up into the doorway, or press Grab |

## Techniques (fighting manuals)
| Technique | Input | Where |
|---|---|---|
| Shoulder Charge | While running, Punch | Benny's Rec Center |
| Rising Kick | Hold Guard + Kick | Benny's |
| Spin Sweep | Hold Guard + Punch | Benny's (after Act I) |
| Guard Counter | Punch right after a perfect guard | Benny's (Act II) |
| Oath Breaker | Hold Kick ~1 s, release | Benny's (Act III) |
| Heel Drop | In the air, Punch | Hollis Books / escort reward |
| Rapid Fists | Keep pressing Punch after the 2nd punch | Hollis Books |
| Quick Hands | Automatic: instant pickups; Guard catches thrown objects | Hollis Books (after Act I) |
| Giant Swing | While carrying an enemy, Punch | Hollis Books (Act II) |
| Thunder Slam | In the air, Guard | Hollis Books (after Otto) |

No technique needs more than one held button plus one press, so all of them work on keyboard, controller and touch.
