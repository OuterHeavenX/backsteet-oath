# Character assets

All files below are procedurally generated by tools/art/gen_characters.py; original; project-owned.
No third-party, traced or ROM-derived imagery is used. Rebuild with:

```
python3 tools/art/gen_characters.py
```

Sprite sheets follow `docs/ART_BIBLE.md` section 3: 512x512 PNG, 8x8 grid of 64x64 cells, frames 0-57 in art-bible order (cells 58-63 empty), foot anchor (32, 60), facing right. Each sheet has a JSON sidecar with `anims` (name -> [start, count]) and `hand` (58 x [x, y, angle_deg] front-hand grip points; carry frames give the top-centre point between the raised hands).

Characters flagged *civilian* use relaxed idle/walk/run arm poses instead of a fighting guard; all other frames are identical in layout.
