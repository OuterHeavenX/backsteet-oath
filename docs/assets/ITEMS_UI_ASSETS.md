# Items, FX, UI and font assets

All files below are original and procedurally generated by deterministic Python scripts in `tools/art/` (no third-party, traced, ROM-derived or commercial-font material). Project-owned. Rebuild and verify with:

```
python3 tools/art/gen_font.py            # fonts (add --preview DIR for sample renders)
python3 tools/art/gen_items_ui.py        # weapons, icons, fx, pickups, ui, logo (add --preview DIR, --only ...)
python3 tools/art/verify_items_ui.py     # checks every file below exists at the contracted size + JSON parses
```

Generator modules: `gen_items_ui.py` (entry point, JSON sidecars) uses `pixlib.py` (canvas/shading/outline toolkit), `items_weapons.py`, `items_icons.py`, `items_fx.py` (FX + pickups), `items_ui.py`, `items_logo.py`; `gen_font.py` builds the TTFs from the glyph bitmaps in `font_glyphs.py` (also used to stamp text onto UI art). Palette and 1px `#1a1220` outline follow `docs/ART_BIBLE.md`.

Every outline is the merged rectilinear trace of the pixel bitmap on the integer pixel grid (outer contours clockwise, counters counter-clockwise), so at 8/16 px (Oath Pixel) and 12/24 px (Oath Big) rendering lands exactly on the grid: verified with PIL/FreeType antialiased rendering producing 0 partial-coverage pixels. Tables: glyf/loca, cmap (format 4), hmtx/hhea, OS/2 v4, name (family, full, PostScript `OathPixel-Regular` / `OathBig-Regular`, license note), post v2 with glyph names, head with fixed timestamps (byte-identical rebuilds).

Recommended Godot import (FontFile): Antialiasing = None (Grayscale is also clean at integer sizes), Hinting = None, Subpixel Positioning = Disabled, Generate Mipmaps = off; use font sizes 8 or 16 for Oath Pixel and 12 or 24 for Oath Big.

License note: both fonts are original, project-owned designs. The project may choose to release them under the SIL Open Font License 1.1; the `name` table license string says so.

## 7. Notes / deviations

- `road_sign`: drawn as the rectangular orange DETOUR plate with an arrow (the diamond would be too small for legible SLOW lettering at 14 px).
- The logo letterforms are built from the Oath Big glyphs, upscaled and re-cut at 1x with 45-degree chamfers, so the title is crisp single-pixel art rather than blocky upscaled pixels.
- `icon.png` (256x256) is a 4x nearest-neighbour upscale of the native 64x64 `icon_64.png`.
- `shadow.png` uses near-black `#0a060e` with alpha quantised in ~5% steps (max 40%), matching the engine ground-shadow spec.
- `button_pressed.png` is the same 24x16 size as the others, with the face shifted down 2px so labels can be offset by +2px when pressed.
